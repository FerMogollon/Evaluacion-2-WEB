# Frontend de AstroLogistics

La guía completa de instalación, configuración, ejecución y funcionamiento del proyecto está en [AstraLogistics/README.md](../README.md).

Para iniciar solo este frontend:

```powershell
npm install
npm run dev
```

El frontend espera que el backend esté disponible en `http://localhost:3000`. Puedes cambiar esa dirección definiendo `VITE_API_URL` en un archivo `.env` de esta carpeta y reiniciando Vite.
